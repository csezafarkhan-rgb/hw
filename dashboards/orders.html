Which file is which?
📦 Order file (.csv)
ShipStation → Orders → Export → CSV. One row per order line, so a 3-item order is 3 rows.
Gives: order number & date, customer and address, SKU, quantity, unit & extended price, order total, payment method, sales channel (ProviderName), label-create date, ship date, tracking, carrier, delivery date and delivery message.
→ Powers Orders and Backorder / No Movement. Without it the dashboard is empty.
🚚 Shipment file (.xlsx)
ShipStation → Shipments → Export → Excel. One row per shipment / label.
Gives: shipment ID, ship date, carrier & service, tracking, carrier fee vs shipping paid, weight (oz), zone, warehouse and qty shipped.
→ Powers Shipping / Portals — cost per portal, carrier mix, zone and margin. Optional; the other tabs work without it.
The two are matched on order number, so export the same date range from each. Files are read in your browser — nothing is uploaded anywhere.
