Import your two ShipStation exports

This dashboard uses two different files from ShipStation. You can import either one first — they combine automatically.

📦 Order file (.csv)

The ShipStation Orders export. Gives the order list, order status & totals, and each order's delivery status (delivered / in transit / no movement).

→ Powers the Orders and Backorder / No Movement tabs.

🚚 Shipment file (.xlsx)

The ShipStation Shipments export. Gives which portal / marketplace shipped each order, plus carrier, cost, service, weight & zone.

→ Powers the Shipping / Portals tab and adds those columns onto the Orders table.

…or just drag either file anywhere onto this window — it's detected automatically by type.
