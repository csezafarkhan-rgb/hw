💾 Backup & Restore

Downloads or restores every workspace database in this browser — users, containers, products, inventory, orders, financial, attendance. Great for moving to another browser, sharing with a teammate, or keeping periodic snapshots. Nothing leaves your computer unless you send the file yourself.
1Export — download a JSON backup of everything in this browser
2Restore — replace this browser's data with a backup file
⚠︎ Restore replaces current data. Take an export first if you want a rollback point. After restore, sign in again on the workspace.
